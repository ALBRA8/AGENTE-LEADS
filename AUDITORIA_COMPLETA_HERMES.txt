================================================================================
                        1. RESUMEN EJECUTIVO
================================================================================

El AGENTE LEADS es un sistema de prospeccion automatizada basado en:
- Modelo: Kimi K2.5 via NVIDIA NIM API
- Stack: TypeScript + Node.js + SQLite
- Bot: Telegram (grammy framework)
- Scraping: Apify + Playwright (stealth)

La arquitectura es solida y bien estructurada, pero existen dependencias 
criticas no configuradas que impiden el funcionamiento completo en produccion.

PUNTOS FUERTES:
+ Buena separacion de responsabilidades (/agent, /bot, /config, /database)
+ Sistema de memoria persistente con SQLite
+ Retry logic con exponential backoff
+ Bridge Python para scraping stealth
+ Whitelist de seguridad por Telegram ID

PUNTOS DEBILES:
- APIFY_TOKEN no configurado (bloquea scraping principal)
- Verificacion de email basica (servicio gratuito)
- Transcripcion de voz sin implementar (placeholder)
- Base de datos vacia (ningun lead guardado todavia)

PROBLEMA #2: QUERY DE BUSQUEDA MUY LIMITADA
--------------------------------------------
Archivo afectado: scrape_instagram_leads.ts
Severidad: MEDIA

Query actual:
```typescript
queries: `site:instagram.com + ${query} + @gmail.com`
```

Problemas:
- Solo busca @gmail.com
- Ignora: @outlook.com, @yahoo.com, @hotmail.com
- Ignora emails corporativos (@empresa.com)
- "site:instagram.com" en Google rara vez muestra emails publicos
- Instagram bloquea scraping agresivo

Solucion:
```typescript
queries: [
  `site:instagram.com ${query} "@gmail.com"`,
  `site:instagram.com ${query} "@outlook.com"`,
  `site:instagram.com ${query} "email" "bio"`,
  `site:instagram.com ${query} "contact"`,
  `site:instagram.com ${query} inurl:"/business/"`
]
```
